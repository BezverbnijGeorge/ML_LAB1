# ADAC cars reliability — логістична регресія

Модель прогнозує бінарну ціль `is_high_risk` — чи перевищує частота поломок авто 15 на 1000 — за трьома ознаками: вік, клас авто, група марок.

## Запуск

Скрипти читають і пишуть файли за відносними шляхами, тому запускати їх треба з кореня репозиторію.

```bash
python statistics_parser.py    # 1. збір даних з сайту -> adac_raw_data.csv
python convert_data.py         # 2. підготовка ознак   -> adac_ml_ready.csv
python logistic_regresion.py   # 3. навчання й оцінка  -> results/
```

Кроки 1 і 2 можна пропустити на момент 05.10.2026 в файлах збережена актуальна статистика.

Оцінку можна повторити окремо, без перенавчання — вона читає модель і вибірки з `results/`:

```bash
python evaluate_model.py
```

## Скрипти

### `statistics_parser.py`

Збирає таблицю Pannenstatistik із сайту ADAC, потрібно зареєструвати в акаунт на сайті.
Результат зберігається в `adac_raw_data.csv`:

| Колонка | Зміст |
|---|---|
| `vehicle_class` | клас авто (назви німецькою, як на сайті) |
| `model` | марка і модель |
| `year` | рік першої реєстрації |
| `defect_rate` | кількість поломок на 1000 авто |



### `convert_data.py`

Будує ознаки із сирих даних і зберігає `adac_ml_ready.csv`:

| Колонка | Як отримана |
|---|---|
| `age_years` | `2025 − year` |
| `vehicle_class` | без змін |
| `origin_group` | марка (перше слово назви моделі, з окремими виправленнями) → група за словником `group_mapping`; марки поза словником отримують `Other` |
| `is_high_risk` | `1`, якщо `defect_rate > 15`, інакше `0` |

Назва моделі та сам `defect_rate` у готовий датасет не потрапляють.

### `logistic_regresion.py`

1. **Кодування.** Категоріальні ознаки кодуються через `pd.get_dummies(drop_first=True)`; перша категорія кожної ознаки стає базовою.
2. **Розбиття.** Стратифіковане за `is_high_risk`: рядки кожного класу перемішуються і діляться окремо, щоб частка класів у вибірках збігалась.
3. **Масштабування.** Стандартизація `(x − mean) / std`; `mean` і `std` рахуються лише на навчальній вибірці.
4. **Навчання.** Пакетний градієнтний спуск без регуляризації, початкові ваги нульові, до ознак додається стовпець одиниць для вільного члена.
5. **Збереження.** Модель, вибірки та їх розподіл записуються в `results/`.
6. **Оцінка.** Викликається `evaluate()` з `evaluate_model.py`.

Параметри задані константами на початку файлу та перед циклом навчання:

| Параметр | Значення | Зміст |
|---|---|---|
| `TEST_SIZE` | `0.2` | частка тестової вибірки |
| `RANDOM_SEED` | `42` | seed розбиття; з тим самим значенням розбиття відтворюється |
| `alpha` | `0.5` | швидкість навчання |
| `steps` | `3000` | кількість ітерацій градієнтного спуску |
| `RESULTS_DIR` | `results` | тека для вихідних файлів |

### `evaluate_model.py`

Відновлює модель із `model_params.csv`, застосовує її до `train_set.csv` і `test_set.csv` та рахує метрики. Вибірки кодуються так само, як при навчанні, а набір і порядок колонок вирівнюються за збереженою моделлю, тому відсутня у вибірці категорія помилки не викликає.

Функції:

- `sigmoid(z)` — логістична функція з обрізанням аргументу до `[−250, 250]`
- `predict_proba(df, model_df)` — імовірність класу 1 для сирих рядків
- `compute_metrics(y, p, threshold)` — метрики та матриця помилок
- `evaluate(results_dir)` — повна оцінка зі збереженням файлів і виводом у консоль

Поріг класифікації — константа `THRESHOLD = 0.5`.

## Вихідні файли (`results/`)

| Файл | Зміст |
|---|---|
| `model_params.csv` | `feature`, `theta`, `mean`, `std`; рядок `intercept` — вільний член, для нього `mean` і `std` порожні |
| `train_set.csv`, `test_set.csv` | рядки вибірок у вихідному вигляді; `row_id` — номер рядка в `adac_ml_ready.csv` |
| `split_distribution.csv` | для кожного значення цілі та кожної ознаки: кількість і частка в навчальній і тестовій вибірках; рядок `total` — розміри вибірок і їх частки від усього датасету |
| `test_predictions.csv` | тестові рядки з колонками `probability`, `predicted`, `correct` |
| `metrics.csv` | метрики для обох вибірок (колонки `train`, `test`) |

Метрики в `metrics.csv`:

| Метрика | Зміст |
|---|---|
| `samples` | кількість рядків |
| `accuracy` | частка правильних прогнозів |
| `precision` | `tp / (tp + fp)` |
| `recall` | `tp / (tp + fn)` |
| `f1` | гармонійне середнє precision і recall |
| `log_loss` | середня логарифмічна втрата |
| `baseline_accuracy` | точність моделі, яка завжди прогнозує найчастіший клас |
| `tp`, `tn`, `fp`, `fn` | елементи матриці помилок; позитивний клас — `is_high_risk = 1` |

## Структура

```
statistics_parser.py     збір даних з adac.de
convert_data.py          підготовка ознак
logistic_regresion.py    розбиття, навчання, збереження
evaluate_model.py        оцінка на навчальній і тестовій вибірках
adac_raw_data.csv        сирі дані
adac_ml_ready.csv        датасет для навчання
results/                 вихідні файли останнього запуску
```
